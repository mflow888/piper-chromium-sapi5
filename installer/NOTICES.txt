Piper SAPI5
==========

This software does not contain malicious code.
It does not collect data, it does not phone home, and it does not start when Windows starts.
Speech is synthesized on this computer from the voice files you installed.

The engine source (the src directory of the project) is Apache License 2.0.
Other pieces keep their own licenses. The full texts are in the licenses directory.

- sherpa-onnx 1.13.7
  https://github.com/k2-fsa/sherpa-onnx
  Apache License 2.0
  The Windows build is linked with eSpeak NG data.

- ONNX Runtime
  https://github.com/microsoft/onnxruntime
  MIT License

- eSpeak NG (espeak-ng-data)
  https://github.com/espeak-ng/espeak-ng
  GNU General Public License version 3

Voice models are the official Piper voices published by the Rhasspy project, plus the
Polish BASS HIGH voice already prepared for this project. Each model card is stored
under licenses\karty. Those cards name the dataset and its license (CC0, CC BY 4.0,
Apache 2.0, or another license stated by the voice author).

This project was written with the help of Cursor (https://cursor.com).
The goal is to make Piper SAPI5 voices available in Brave, Chrome, and other
Chromium browsers. Narrator and many Windows desktop programs may not use them.
