# Piper versions

These installers are Piper SAPI5 1.4.0. The number in the table is the Piper release that exported each voice, taken from the `piper_version` field in that voice model.

One language installer can contain voices exported by more than one Piper release. The Windows package version stays 1.4.0 either way.

The models come from the [official Piper voice catalog](https://huggingface.co/rhasspy/piper-voices).
